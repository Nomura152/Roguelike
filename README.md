# Roguelike

Unityの授業用に制作した、ローグライクゲームです。

ゲームの設計・実装と、その制作過程を説明する教材の作成も行いました。授業資料では、ゲーム仕様の整理から必要なクラスを考え、実装までの手順を記載しています。
リポジトリでは、開発で作成したC#スクリプトのみを抜粋しています。

## 主な実装

- プレイヤーの移動、敵の追跡、攻撃・ダメージ処理
- 5種類の武器
- 経過時間に応じたWaveの切り替えと敵生成
- アイテムドロップ処理、回復・経験値アイテムの実装
- レベルアップとアップグレード候補の抽選・獲得
- ゲーム進行と開始・終了演出

### 武器の設計と拡張性

武器は、設定を保持する`WeaponData`、レベルごとの設定を保持する`WeaponLevelData`、実体のベースとなる`WeaponBase`を定義し、`WeaponController`が所持する武器を管理します。
新規武器は`WeaponBase`を共通で利用し、武器ごとの処理を追加する構成としました。

### アップグレードの抽選・適用

レベルアップ時のアップグレードは`UpgradeManager`によって抽選・適用を行います。
アップグレードの抽選は、以下の条件で候補を絞り込み、抽選しています。

- 「武器」または「バフ」をランダムに3種類抽選
- 最大レベルとなった武器は、候補から除外
- 武器の所持スロットが埋まっている場合、新規武器を候補から除外
- 武器候補がない場合、空いた抽選枠はすべてバフから選択

### 攻撃処理の汎用化

ダメージを受ける側の共通インターフェースとして`IDamageable`を定義しています。攻撃側は`SingleAttackHitbox`や`RepeatAttackHitbox`で判定を行い、相手のダメージ処理を呼び出します。
